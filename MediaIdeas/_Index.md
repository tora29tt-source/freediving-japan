# 記事・メディア企画 ネタ帳

新しい企画は [[Templates/Media Idea Template|Media Idea Template]] からノートを作成し、このフォルダに追加する。
判断基準・カテゴリ定義の詳細は [[MEDIA_OPS]] を参照。

一覧管理は [[MediaIdeas/MediaIdeas.base|企画管理Base]] から（ステータス別に絞り込み・並び替え可能）。

## カテゴリ早見表（MEDIA_OPS.md より）

| カテゴリ | 内容 | 優先度 |
|---|---|---|
| A. 入門・体験 | 検索流入記事（耳抜き・費用等） | SEO 土台 |
| B. 身体・科学 | CO2・哺乳類潜水反射等 | 信頼蓄積 |
| C. 海・スポット | スポット紹介・旅行 | マッチング送客 |
| D. 競技・大会 | ランキング・大会レポート | 競技者向け |
| E. インタビュー | 被取材者の拡散 | ◎ 看板 |
| P. 人物メディア | Takuya主語 or ゲスト主語 | ◎ 看板 |
| Q. 業界×期待感 | ローンチ期の期待感記事 | ◎ 初期優先 |
| S. シリーズ連載 | 継続連載 | 回遊 |
| T. エンタメ | 拡散・一般層向け企画 | 拡散 |
