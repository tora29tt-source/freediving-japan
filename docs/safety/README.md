## 運用原則

1. **同意書は「免責の魔法」ではない**。故意・過失があれば責任は免れない（消費者契約法8条）。同意書の本当の役割は ①リスクの説明義務を果たした証拠 ②健康申告の証拠 ③参加者の安全意識の醸成
2. **最大の防御は保険と安全基準の運用**。書類はその記録装置
3. 事故報告は懲罰でなくデータとして扱い、報告文化を守る（隠蔽のみを罰する）
