# Freediving Japan 掲載事業者 安全基準（Safety Standards v1.0）

> **位置づけ**：Freediving Japan（以下FJ）に掲載されるインストラクター・ショップが遵守すべき安全基準。承認申請時に同意を必須とし、公開ページで消費者にも開示する。「FJ掲載＝この安全基準を満たしている」をブランド価値の中核にする。

---

## 1. 掲載の必須要件（これを満たさない事業者は承認しない）

| # | 要件 | 確認方法 |
|---|---|---|
| 1 | 指導団体の有効なインストラクター資格（AIDA / Molchanovs / PADI Freediver / SSI Freediving / CMAS / NAUI 等）を保有していること | 資格証の提出（admin承認時に確認） |
| 2 | **業務中の事故を補償する賠償責任保険に加入していること**（指導団体系保険等。レジャー用個人保険では不可） | 保険証券・加入証明の提出、年1回更新確認 |
| 3 | CPR・応急処置の有効な認定（EFR等・2年以内）を保有していること | 認定証の提出 |
| 4 | FJ提供テンプレート同等以上の参加同意書・健康チェック票を全参加者から取得していること | 承認時に使用書式を提出 |
| 5 | 緊急時対応計画（EAP）を開催地ごとに文書化していること | 承認時に提出（§4テンプレート参照） |

## 2. 開催時の安全ルール（最低基準）

- **直接監督**：体験・講習中の潜水は必ずインストラクターの直接監督下で行う。ワンナップ・ワンダウン（1人が潜る間、1人が水面で監視）を原則とする
- **人数比率**：水域でのインストラクター1名あたりの参加者数上限——体験（初心者）4名／講習6名／引率スノーケリング8名を上限目安とし、海況により減じる
- **機材**：フロート・視認性の高いブイ・レスキュー用マスク/フィンを常備。深度系プログラムでは緊急酸素の配備を強く推奨（合宿・競技系は必須）
- **中止基準**：開催者は風速・波高・視界・水温の中止基準を事前に定め、基準超過時は躊躇なく中止する（中止判断で不利益を被らないようFJはキャンセルポリシー表示で支援）
- **飲酒・体調**：飲酒後12時間以内の参加不可。当日の健康チェック（E欄）を必ず実施

## 3. 事故・インシデント報告義務

1. FJ経由の予約で発生した事故（医療機関受診を要するもの）およびニアミス（ブラックアウト・LMC・救助を要した事象）は、**72時間以内にFJへ報告**する
2. FJは報告を掲載可否の懲罰目的ではなく、業界の安全データ蓄積と再発防止のために扱う（報告文化を守るため、誠実な報告を掲載停止理由にしない。虚偽・隠蔽は掲載停止理由とする）
3. 重大事故（死亡・後遺障害・報道対象）の場合、FJと事業者は対応方針（公表・遺族/家族対応・警察/海保対応）を協議する

## 4. EAP（緊急時対応計画）テンプレート

開催地ごとに以下を1枚にまとめ、スタッフ全員と共有する。

```
開催地名／水域：
最寄りの医療機関（高気圧酸素治療可否）：名称・電話・所要時間
救急要請：118（海上保安庁）／119　通報時に伝える位置情報：
緊急酸素の保管場所：
搬送手段（車両・ドライバー）：
役割分担：レスキュー役／通報役／記録役
DAN JAPAN緊急ホットライン等の連絡先：
```

## 5. 運用（FJ側）

- 承認フロー（`instructors.status`）に本基準への同意チェックを組み込む（申請フォームに同意必須項目を追加：実装は別タスク）
- 保険・資格の有効期限を年1回確認（admin画面にリマインダー：将来実装）
- 本基準は公開ページ `/safety/` として掲載し、「探す」側のユーザーにも見せる（信頼の差別化要素）
