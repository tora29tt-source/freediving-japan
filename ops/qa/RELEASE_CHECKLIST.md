# リリース前チェックリスト

> 使い方：実装した領域のセクションだけ確認する。全部やる必要はない。
> 機械チェック（`node ops/qa/smoke_test.mjs`）を先に回してから、ここの人間確認に進む。
> 確認したら DEV.md の「実機確認未」記載を消して日付を入れる。

## 0. 共通（毎回）

- [ ] `node ops/qa/smoke_test.mjs` が FAIL 0 件
- [ ] `node ops/scan_followups.mjs` で未実施SQLが増えていない
- [ ] スマホ幅（375px）で表示崩れがない
- [ ] コンソールにエラーが出ていない（F12）
- [ ] 未保存警告（beforeunload）が編集ページで機能する

## 1. explore（マッチング）

- [ ] 検索バー（トップ→explore）のURLパラメータ絞り込みが効く
- [ ] 都道府県フィルタで絞れる／「海外」も出る
- [ ] コース無しショップが shops.html に表示される
- [ ] listing.html：コース詳細＋予約カレンダーが出る／listing無しなら profile.html にフォールバック
- [ ] profile.html：bio・在籍インストラクター・コース一覧・レビューが出る（予約カレンダー無し）
- [ ] ショップ名義商品（instructor_id無し）が正常表示される

## 2. 予約・決済

- [ ] 空き枠カレンダー→Stripe Checkout（テストカード 4242…）→success.html まで通る
- [ ] 予約が bookings に status=paid で入る
- [ ] 満席の枠が選べない／非アクティブ枠が出ない
- [ ] キャンセルURLで listing ページに戻れる

## 3. pro（インストラクター/ショップ管理）

- [ ] ショップロールで自ショップの商品・予約・問い合わせ**のみ**見える（在籍インストラクター個人の商品が混ざらない）
- [ ] コース作成→explore に反映される
- [ ] ショップカバー画像の位置調整が保存される（要 shops.cover_position カラム）

## 4. メディア

- [ ] 記事プレビューと本番表示が一致する
- [ ] 著者紹介文が反映される（要 articles.author_bio カラム）／空欄ならデフォルト文
- [ ] editor ロールで公開ボタンが出ない／承認依頼→admin側でレビュー待ちに出る
- [ ] トップの記事カードが実記事に飛ぶ

## 5. ツール（training-log / sta-timer）

- [ ] ログ保存→履歴→編集→URLシェアが通る
- [ ] STA 10分超の入力が化けない（4桁 99:59 対応済み）
- [ ] ベストタイム計算が正しい（STA系優先・インターバルのレスト混入なし）

## 6. 認証・権限

- [ ] Googleログイン→リダイレクト→ログイン状態でマイページ表示
- [ ] 未ログインで admin/ に入れない
- [ ] editor で admin のメディアタブ以外が見えない

## 7. 削除まわり

- [ ] ユーザー操作の削除がソフトデリート（deleted_at）で行われ、一覧から消える
- [ ] 削除後に同じ slug / aida_id で再作成できる
